# Specimen plates go here, one per specimen, named for the slug.
#
#   bulbasaur.webp   venusaur-mega.webp   wo-chien.webp
#
# The name must match the key used in public/field-notes.txt and by PokeAPI.
# Run `npm run plates` after adding any, or just `npm run build`, which does it.
#
# Where a plate exists the site shows it instead of the sprite. Where one does
# not, the sprite stands in. The set can therefore arrive one drawing at a time.
#
# A plate can be drawn by hand and dropped in, or drawn in code: a module in
# plates-src/ (see bulbasaur.mjs) rendered here by `npm run plates:draw`.
