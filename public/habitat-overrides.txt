=====================================================
FOLIA CODEX — HABITAT OVERRIDES
=====================================================
This is a plain text file. Open and edit it with Notepad, TextEdit, or
any text editor — no coding required.

By default, every specimen's "Likely Habitat" is guessed automatically
from its secondary type (see src/data/habitatMap.js for that baseline —
e.g. Grass/Water defaults to "Wetland & Aquatic"). This file lets you
OVERRIDE that guess for one specific specimen when its actual morphology
says something different than its type pairing would suggest — the same
way Cacnea (Grass/Dark) is really a desert cactus.

HOW TO ADD ONE:
1. Copy the TEMPLATE block below and paste it anywhere in this file.
2. Change "template" on the first line to the specimen's exact name (same
   spelling PokéAPI uses — lowercase, hyphens for spaces, e.g. "cacnea",
   "exeggutor-alola").
3. Fill in "habitat_name" and "description". Both are required — a
   partial override isn't supported, so write the whole replacement.
4. Save the file. Refresh the app in your browser to see it appear.

Leave a specimen out of this file entirely if the automatic type-based
guess is fine as-is — most specimens won't need an entry here.
